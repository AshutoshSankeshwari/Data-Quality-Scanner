# LOG_TRACKER.md

**Project:** Data Quality Scanner
**Purpose:** Track major changes made to the application over time, starting with the V2 planning baseline.
**Note:** This log tracks *planned and implemented* changes. As of this baseline entry, no V2 code has been written — only the three V2 PRDs and this tracker exist. Status values reflect that.

---

## How to Use This Log

Each row documents one discrete change (or planned change). Update this file whenever a V2 design decision is finalized, implementation work begins/completes, or a deviation from a PRD occurs. Do not edit historical rows retroactively except to correct factual errors — add a new row instead.

| Column | Meaning |
|---|---|
| Date | Date the change was decided/made |
| Version | Application version this applies to (e.g., V1.0, V2.0-planning, V2.0) |
| Change | Short description of what changed |
| Reason | Why the change was made |
| Affected Component | File(s)/module(s)/screen(s) involved |
| V1/V2 | Whether this is a V1 fact being documented, or a V2 change |
| Status | Planned / In Progress / Implemented / Verified |
| Notes | Additional context, links to relevant PRD section |
